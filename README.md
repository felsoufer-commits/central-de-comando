# Central de Comando — MVP Spec v3.0

Sistema para interromper padrões de repetição comportamental.
Universo Comando.

## Deploy no Vercel (3 minutos)

1. Acesse [vercel.com](https://vercel.com) e crie uma conta (pode usar GitHub)
2. Clique em **"Add New Project"**
3. Importe este repositório do GitHub
4. O Vercel detecta automaticamente que é Vite + React
5. Clique em **"Deploy"**
6. Compartilhe o link gerado com seus alunos

## Deploy no Netlify (3 minutos)

1. Acesse [netlify.com](https://netlify.com) e crie uma conta
2. Arraste a pasta `dist` (após rodar `npm run build`) para a área de upload
3. Pronto — link gerado automaticamente

## Rodar localmente

```bash
npm install
npm run dev
```

## Build para produção

```bash
npm run build
```

Os arquivos prontos estarão na pasta `dist/`.
